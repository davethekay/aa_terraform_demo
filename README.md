This is a demo project for learning how to write a Terraform script using Amazon Web Service to create a VPC.
This is work I do to study new technologies and produce results by Hands-On means, which is the best teacher for learning.

I used the UI in AWS to build the VPC first and used that as a template to translate this building into Terraform scripts to create subnet(s), 
external EC2 instances for ECS (ECS Anywhere), Security Group(s) (IAM), AMI (AWS Optimized EC2 Instance for ECS), Internet Gateway (NAT), and 
finally private EC2 instance for a database (MySql)

Work in Progress. Completed all but the private EC2 Instances for database using NAT Gateway.
